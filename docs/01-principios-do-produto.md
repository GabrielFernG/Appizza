# 01 — Princípios do Produto

- Configuração acima de hardcode.
- Operação real acima de estética.
- Cliente deve saber o que está acontecendo.
- Histórico não deve ser sobrescrito.
- Estado de negócio é explícito.
- Interface simples; domínio pode ser sofisticado.
- Backend é autoridade de regra/preço/permissão.
- Figma é referência.
- Tecnologia gratuita/open-source por padrão.
- Evolução sem reescrita.
- Segurança e auditoria desde o início.
- Multiestabelecimento preparado desde o modelo.
