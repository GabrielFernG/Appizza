# Definition of Done

Uma tarefa só está pronta quando:
- [ ] regra funcional atendida;
- [ ] autorização backend aplicada;
- [ ] migrations/constraints/índices revisados;
- [ ] unit tests para regra crítica;
- [ ] integration tests quando toca DB/API;
- [ ] idempotência testada quando aplicável;
- [ ] logs sem dados sensíveis;
- [ ] build limpo;
- [ ] documentação atualizada;
- [ ] erros ProblemDetails documentados;
- [ ] observabilidade mínima adicionada.
