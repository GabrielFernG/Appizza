# Checklist de Pull Request

- [ ] escopo pequeno e claro;
- [ ] sem regra nova só no código;
- [ ] sem dependência paga inesperada;
- [ ] sem acesso direto indevido entre módulos;
- [ ] migrations reversíveis/seguras;
- [ ] testes;
- [ ] segurança;
- [ ] concorrência;
- [ ] API/eventos compatíveis;
- [ ] documentação.
