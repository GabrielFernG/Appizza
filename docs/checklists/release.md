# Checklist de Release

- [ ] migrations validadas em staging;
- [ ] backup/restore testado;
- [ ] health checks verdes;
- [ ] Outbox sem backlog anormal;
- [ ] providers de pagamento homologados;
- [ ] configuração mínima definida;
- [ ] versão mínima de tablet definida;
- [ ] rollback documentado;
- [ ] smoke test do fluxo ouro;
- [ ] monitoramento ativo.
