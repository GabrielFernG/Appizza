# Template de Prompt por Fase

Leia `AGENTS.md` e toda a documentação relevante.

Implemente a Fase X de `docs/15-roadmap-desenvolvimento.md`.

Antes de alterar arquivos:
1. resuma as regras que afetam esta fase;
2. liste arquivos/projetos;
3. liste endpoints;
4. liste eventos;
5. liste tabelas/migrations;
6. liste testes.

Implemente somente esta fase. Ao final:
- execute build;
- execute testes;
- informe pendências;
- atualize documentação se necessário.
